ads-automation-test

A personal developer tool by Akmal Dzakwan Faiz (GitHub: AzafaDev)

ads-automation-test is a command-line tool that manages ad campaigns on the developer's own ad accounts through the platforms' official APIs, including the Pinterest API v5. It is used by one person, the developer, with his own Pinterest business account. It has no public users, no sign-up and no web interface.

What it does on Pinterest

  • Reads the developer's own ad account, campaigns, ad groups and ads.
  • Creates traffic campaigns that are always paused, with a fixed daily budget, and ad groups that promote the developer's own Pins.
  • Changes budgets and bids, pauses campaigns, and starts a campaign only after the developer approves it himself.
  • Reads daily campaign reports: spend, impressions, clicks and conversions.

Safety rules built into the tool

  • Every campaign is created paused and checked after creation.
  • Daily budget limits are enforced in code before any change is sent.
  • Nothing starts spending without the developer's own confirmation.
  • Every change is written to a local log.

Testing happens first in the Pinterest API sandbox.
