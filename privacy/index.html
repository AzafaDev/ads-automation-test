Privacy policy: ads-automation-test

Last updated: 22 October 2026

ads-automation-test is a personal developer tool built and run by Akmal Dzakwan Faiz. It manages ad campaigns through the Pinterest API on the developer's own Pinterest business account only. It has no other users, no sign-up and no web interface, and it never accesses other people's Pinterest accounts.

Data the tool accesses

  • The developer's own ad account details: name, id, currency and status.
  • Campaigns, ad groups and ads in that ad account, with their budgets, bids and statuses.
  • Pins and boards of the developer's own account, used as ads.
  • Campaign reports: spend, impressions, clicks and conversions.

The tool does not request or store any data about people who see or click the ads.

How the data is used

Only to create, change, pause and report on the developer's own campaigns. Reports may be read by an AI assistant (Claude by Anthropic) that the developer uses to operate the tool on his own machine.

Where the data is kept

On the developer's own computer. The access token is kept in a local file that only the developer's user can read. A local log records each change the tool makes (time, campaign id, old and new values). Data is kept only as long as the developer needs it for managing and testing his campaigns.

Sharing

No data is sold. No data is shared with third parties for their own use.

Deletion and revoking access

The developer can delete the local data at any time. Access ends when the app's access is revoked in Pinterest settings.

Contact

Through the issues of this site's repository: github.com/AzafaDev/ads-automation-test/issues.
